# Key files by feature

Read when you need to find where a feature lives (hook, bookmarks, links, project board, fonts and Claude button, OSC 7501, turn end, focus trap, announcer, logger, health script) or which check script covers it. Moved word for word from CLAUDE.md's Key Files (S46 slimming, 2026-11-08).

- `resources/claude-code-stop-hook.sh` + `scripts/probe-stop-hook.sh` — the Claude Code Stop hook (protocol in its header) and its synthetic-stdin probe; `src/main/claude-hook.ts` installs it (bundle with esbuild + a driver to run the real installer headlessly, as S40 did).
- `scripts/forge-package.sh` — the one entry point for local builds (post-commit hook, `npm run package`); runs Forge on a Node ≥ 22.13.
- `src/renderer/components/bookmarks-panel.ts`, `src/main/bookmarks.ts` — bookmarks sidebar; `src/main/clipboard-image.ts` — image paste; `src/renderer/services/startup-command.ts` — startup command shared by app start and bookmark open.
_Session 20–25 plan files, the S25 render-snapshot notes, the S20 reasoning report and the rejected S40 look mocks moved → `docs/session-archive.md` (S44 slimming)._
- `src/renderer/services/file-link-provider.ts` — MD link + bare path regex, `event.detail === 2` gate, shared `pushLink()` with security rules (traversal rejection, cwd-relative resolution). OSC 8 links landed S43 (`services/osc8-links.ts`, `link-target.ts`); every file link's open/editor/reveal decision is made in main by `src/main/link-open-policy.ts`.
- v1.15 (S44), project board: `src/main/project-board.ts` (list parse matching `cc`, nesting, layout file, add-row checks), `src/renderer/components/project-board.ts` + `styles/board.css`, `src/renderer/services/project-boards.ts` (which tabs get a board), `open-project.ts` and `project-live-state.ts` (shared with the bookmarks panel). Checks: `node scripts/check-project-board.mjs` (set `CC_LAUNCHER` to the launcher script for the round trip), `JSDOM_DIR=<folder with jsdom ≥ 30> node scripts/check-project-board-ui.mjs` and `…-wire.mjs`; jsdom lives outside the repo.
- v1.16–1.17 (S45): `src/main/system-fonts.ts`, `src/renderer/services/system-fonts.ts` and `font-choices.ts` (SF Mono load, the font list; `node scripts/check-fonts.cjs` runs a hidden Electron window and needs the Electron binary, which `npm ci` doesn't fetch: `npx install-electron --no`); the board's Claude button in `project-boards.ts` + `startup-command.ts` (`typeWhenShellReady`); `src/main/close-preconfirm.ts` (last-tab quit) with `scripts/check-close-confirm.mjs` and `check-close-guard.mjs`.
- v1.14 (S43): `src/renderer/services/program-status.ts` (OSC 7501 parser, per-pane records), `pane-activity.ts` + `tab-hover.ts` + `components/tab-hover-card.ts` (hover card and the one activity ranking the dot, palette and bookmarks share), `sessions.ts` + `session-palette.ts` (`listSessions`, palette entries), `patton-osc.ts` (OSC 777 parse incl. `ctx/since/cpt`), `shown-text.ts` (one cleaner for program-supplied text), `scripts/check-link-open-policy.mjs` (drives the real link handler with recorders).
- v1.18–1.19 and main (S46): `src/renderer/services/turn-end.ts` (hook tasks vs a 7501 done), `services/ui-text-scale.ts` + `--ui-scale` in `styles/main.css`, `src/main/close-window.ts` (the renderer closes through main), `close-confirm.ts` + `quit-guard.ts` (in-app quit/close requests, dwell, native fallback), `pty-manager.ts::respawn` (the board in place), `scripts/install-prune.cjs`, `scripts/run-checks.sh` (`npm run check`; `check-close-electron.cjs` pins the `window.close()` trap).
- Pause all (10 Nov 2026): the tab strip's far-right button (`components/tab-bar.ts`, left of it the checkpoint clock; the "⏸" icon while idle, the words in its aria-label and title, a press's result as text for 4 s) types `pause` into Claude panes in every window; every press pauses again, and resume is typed by hand per tab (no Resume button). `src/main/pause-all.ts` (`PauseAllCoordinator`: one press at a time, asks each window, adds up reports, keeps no state between presses), `src/renderer/services/pause-all.ts` (`runPause`: which panes get the word and why not), `Pane.pauseInput` / `typePauseWord` (the checkpoint's submit path), `TabManager.pressPauseAll` / `runPauseAll`. Check: `JSDOM_DIR=<folder with jsdom ≥ 30> node scripts/check-pause-all.mjs`. Logs: `[PAUSE-ALL]` in main.log.
- Tab strip drag space and double-click (12 Nov 2026): a blank `div.tab-bar-drag-space` beside `+` (`components/tab-bar.ts`, CSS in `styles/tabs.css`, always as wide as `+`) drags the window and, on double-click, calls `window.patton.titleBarDoubleClick()`, as does any empty part of `.tab-bar-tabs`; tabs now grow to fill that strip (14 Nov), so the blank space beside `+` (and the strip's left padding) is where the title-bar double-click is always reachable, and a double-click on any tab renames it; a tab's body uses the same private `startWindowDrag` (select on release without moving). The blank areas `preventDefault` the press so focus stays in the terminal (not while a rename box is open), and `dragMoved` stops a press-release-press-drag from zooming. Main's `WINDOW_TITLE_BAR_DOUBLE_CLICK` handler in `main/ipc-handlers.ts` acts on the sender's window only, does nothing in full screen, and maps the Mac's `AppleActionOnDoubleClick` (or the legacy `AppleMiniaturizeOnDoubleClick`) through the pure `main/title-bar-action.ts`. Checks: `JSDOM_DIR=<folder with jsdom ≥ 30> node scripts/check-tab-strip-dblclick.mjs`, `node scripts/check-title-bar-action.mjs` (mapping and the handler's wiring by source regex), and the spacer width in `scripts/check-ui-text-scale.cjs`. Logs: `[WINDOW] title-bar double-click` in main.log.
- Project names (13 Nov 2026): `projectNames` in the store maps a project root, or a linked worktree's own folder, to the name its tabs show. A name set from a worktree's tab names that worktree and shows alone (no ⎇ suffix); `main/projects.ts::projectNameTarget` decides which keys main accepts, `renderer/services/project-names.ts` (`projectDisplay`, `projectTitle`, `projectRenameFields`, `projectNameKey`) is the one display rule every caller uses. Check: `scripts/check-worktree-name.mjs`.
- `src/renderer/services/focus-trap.ts` — reusable modal focus trap. Import as `trapFocus(container)` → returns release fn.
- `src/renderer/services/announcer.ts` — global aria-live regions. Import as `announce(msg, 'polite' | 'assertive')`.
- `src/main/logger.ts` — file logger that tees `console.*` to `~/Library/Application Support/Patton/logs/main.log`. Called once from `main.ts` via `installFileLogger()`.
- `scripts/patton-health.sh` — diagnostic script. `npm run health` or `patton-health` (shell alias) from anywhere. Greps log file + crashpad for session-20 error markers.
- `src/main/projects.ts` (`resolveProject`: nearest git repo, linked worktrees, the top folder under ~/Projects) and `src/main/registered-projects.ts` (S50): a folder the project list registers inside a repo is its own project, not the repo's. The list-file setting is held in the module (set by `ipc-handlers.ts` at registration and in `afterSettingsSaved`); rows keep `{path, real}` resolved once per parse, the parse is cached on file, size, mtime, ctime, inode and home. Check: `node scripts/check-sub-project.mjs` (bundles the real modules against a fixture HOME; its last lines assert the `ipc-handlers.ts` wiring).

## Source tree
Moved word for word from CLAUDE.md's Architecture section (S49 slimming, 2026-11-12).

```
src/
├── main/           # Electron main process (PTY, IPC, menus, settings store, bookmarks,
│                   #   project board, link-open policy, Claude Code hook installer, logger)
├── preload/        # contextBridge API (type-safe IPC bridge)
├── renderer/       # UI components, services, styles
│   ├── components/ # Tab, pane, terminal view, editor input, settings, command palette,
│   │               #   bookmarks panel, project board, tab hover card, etc.
│   ├── services/   # Tab manager, history, keybindings, program status (OSC 7501),
│   │               #   file/OSC 8 links, sessions, project boards, renderer logger
│   └── styles/     # CSS with design tokens + auto dark/light mode
└── shared/         # IPC channel constants, shared TypeScript types, shortcuts
resources/          # Shell integration scripts (zsh, bash) and the Claude Code Stop hook
scripts/            # forge-package.sh, release, health, check-*.mjs suites
```
