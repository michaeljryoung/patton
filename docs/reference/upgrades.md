# npm and Electron upgrade notes

Read before adding or bumping a dependency (native ones above all), or upgrading npm or Electron. Moved word for word from CLAUDE.md's Gotchas (S44 slimming, 2026-11-07).

- **npm 12 skips every dependency's install scripts unless `package.json` approves it** (S39). The install still "succeeds", with a warning, and the build fails later (node-pty unbuilt). After adding or bumping a native dependency, run `npm approve-scripts --allow-scripts-pending` and approve with `npm install-scripts approve <pkg> --allow-scripts-pin=false`. CI's npm (11) ignores the field.
- **Electron 42+ changes that bite** (S37). `npm install` no longer downloads the binary (`npm start` fetches it on first run; `npx install-electron --no` does it by hand); macOS notifications go through UNNotification and need a code-signed app — refusals log `[NOTIFY] Notification not shown`; Electron 44 needs macOS 13+.
- **Electron Forge 8** (S45). Forge 8.0.1 is ESM-only and needs Node 22.13+ (CI runs Node 22); `forge.config.ts` still loads through jiti, so `__dirname` and the TypeScript config work unchanged. Its Vite plugin needs Vite 8 (Rolldown) and emits `.vite/build/main.cjs` and `preload.cjs`, so `package.json` `main` and the preload path in `window-manager.ts` name `.cjs`. Rolldown leaves `"use strict"` out of CJS output unless `output.strict: true` is set, which `vite.main.config.ts` and `vite.preload.config.ts` now do (Vite 5 emitted it). Vite 8 no longer brings esbuild, which `scripts/check-*.mjs` import, so it is a pinned devDependency. `@electron/fuses` 2 is the Fuses plugin's peer. The DMG now lands in `out/make/dmg/arm64/`, not `out/make/` (the release workflow's `find` copes). @electron/packager 20.3 dropped `extract-zip`, so packaging works on Node 26; Forge 7's tree also needed `--allow-git=all` under npm 12 (a git-hosted `@electron/node-gyp`), which Forge 8's tree no longer has.
- **Local DMG builds need Node 22–24** (S45). `macos-alias` (appdmg → electron-installer-dmg → maker-dmg, an optional dependency) uses nan 2.30, which does not compile against Node 26's V8; npm drops the optional package silently and `make` then fails on its DMG step. Install and make under Node 24: `PATH=/usr/local/bin:$PATH npm ci`, then `PATTON_NO_INSTALL=1 PATH=/usr/local/bin:$PATH npm run make`. Packaging alone works on Node 26.
