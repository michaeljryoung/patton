Three changes to see before they ship

The wake tab stays small

Drawn by the real tab strip code and stylesheet. The wake tab keeps the same small size with 2, 12 or 22 other tabs, grouped or not, and goes back to a normal tab when wake ends (row c).

Session bar rows wrap, in one font

Each row's text uses the same font and wraps to three lines before it is cut. Folded, the bar shows only the running count; a failure box appears as "!1" in red only when something failed. Drawn with the real stylesheet.

The icon, if you pick P1

The original portrait in falling digits. Say P2, P3 or A2 instead and that goes in.
